## Incidentes y lecciones
- Git Bash reescribe rutas `/opt`, `/tmp` al pasar a `docker compose run`: `MSYS_NO_PATHCONV=1` en los tests.
- Python en Windows escribe CRLF por defecto: `newline="\n"` en todo archivo que lea una herramienta Linux (`sha256sum -c`).
- `rocker/r-ver` no trae el usuario `ubuntu` de noble: crear uid/gid 1000 explícitamente.
- JuliaCall exige el paquete Julia `Suppressor` además de `RCall`.
- `str.replace` silencioso en parches: verificar siempre con `grep` que el parche aplicó (el primer build corrió con la etapa Julia antigua).
- Pages debe activarse antes del primer push o el job `deploy` falla con 404; basta relanzar.
- La regla `deny` de `rm -rf` ya bloqueó un comando propio: usar el scratchpad y no borrar.
